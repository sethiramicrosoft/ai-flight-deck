              The scanner reads metadata and permissions. It does not retrieve document contents, enable Copilot, remove sharing links, or change tenant configuration.
            
      
          
      
        
      

        
      
          
      Complete workflow
      Follow these steps in order. A forecast is never treated as proof.
      
        
      
        
      
          
      
            
      1
      
            
      
              
      Connect and sign in
      
              
      Select Connect and scan tenant. AI Flight Deck prepares the local connector and opens Microsoft sign-in. Sign in with an account approved for the displayed read-only Graph permissions.
      
            
      
          
      
          
      
            
      2
      
            
      
              
      Let the tool capture the baseline
      
              
      The product runs the bounded read-only scan, stores the evidence in the protected user-local workspace, and opens Assessment automatically. You do not need to find or import a JSON file.
      
            
      
          
      
          
      
            
      3
      
            
      
              
      Import and assess
      
              
      Start with the thirteen-domain estate mission map. Every collector is attempted, and each unavailable permission, licence, workload connection, network test, or attestation is shown against the exact blocked control. Manual import remains available for existing artifacts or offline review.

      Understand the risk
      
              
      Open each finding to understand the rule, source, evidence identifier, severity, and affected resource. Demonstration scenarios show how inherited Microsoft 365 access can become Copilot exposure. Live simulation remains unavailable until the collector has effective permission paths.

      Prepare approved corrections

A successful comparison verifies sharing controls only and never substitutes for the remaining estate domains.
      
              
      
                
              
      
            
      
          
      
        
      

        
      
          
      How the estate-wide decision works
      No single collector or score can approve Microsoft 365 Copilot rollout.
      
        
      
        
      
          
      
            Copilot rollout decision rules and recommended actions
            
      Assessment resultWhat it meansRecommended action
      
            
              
      Domain not collectedA required estate domain has no evidence.No estate decision. Connect the required collector or complete the organizational assessment.
      
              
      Domain partialSome evidence exists, but important controls or populations remain outside scope.Review the stated gaps and collect the missing evidence.
      
              
      Sharing findingThe SharePoint collector found anonymous sharing, organization-wide sharing, or a public workspace requiring validation.Confirm intent with the owner, correct unjustified access, and verify again.
      
              
      Sharing driftThe newer sharing scan has worse counts or newly opened evidence.Investigate the changed evidence while continuing the estate assessment.
      
              
      Sharing controls verifiedThe approved sharing changes were proven by comparable scans.Mark only the sharing workstream as verified. Continue licensing, identity, devices, network, compliance, security, Copilot configuration, agents, and adoption assessment.
      
              
      Estate decision availableEvery required domain has sufficient, current evidence and the approved pilot cohort meets all mandatory gates.Present the evidence-backed pilot recommendation to the accountable decision owner.
      
                  
          
      
        
      

        
      
          
      What each stage is for
      Use the four stages as one connected decision process.
      
        
      
        
      
          
      1. Set up
      Explains permissions, boundaries, commands, roles, and the evidence workflow.
      
          
      2. Assessment
      Maps thirteen estate-readiness systems as online, degraded, or unscanned, then presents evidence from connected collectors.
      
          
      3. Corrections
      Packages proposed actions for approval. Forecast values are planning aids, not tenant changes or proof.
      
          
      4. Decision
      Separates verified sharing changes from the estate-wide readiness decision, which remains unavailable until every mandatory domain has sufficient evidence.

            Decision boundary
            AI Flight Deck provides decision support, not compliance certification. The current live connector supplies partial identity and SharePoint sharing evidence. The estate decision remains unavailable until licensing, identity controls, devices, network, compliance, security, Copilot configuration, agents, and adoption evidence are connected.
