# Acknowledgements and Microsoft tooling references

AI Flight Deck is an independent hackathon prototype. It is not a Microsoft
product or service and is not endorsed as an official Microsoft readiness
assessment.

## Microsoft 365 Copilot Readiness report

- Documentation:
  <https://learn.microsoft.com/en-us/microsoft-365/admin/activity-reports/microsoft-365-copilot-readiness?view=o365-worldwide>
- Publisher: Microsoft
- Contribution to this project: the exported report can provide licence,
  eligible-update-channel, recent Microsoft 365 usage, and suggested-candidate
  evidence for pilot planning.
- Flight Deck treatment: the import retains the report date, privacy state,
  rolling 28-day scope, possible reporting delay, and activity-limited
  population. It is not treated as complete tenant or device proof.

## Microsoft M365 Copilot automated readiness assessment

- Repository:
  <https://github.com/microsoft/m365-copilot-automated-readiness-assessment>
- Publisher: Microsoft
- Upstream license: MIT License, as stated in the Microsoft repository.
- Contribution to this project: its exported recommendation report provides
  technical observations across Microsoft 365, Entra, Defender, Purview, Power
  Platform, Copilot Studio, and Agent 365.
- Flight Deck treatment: the importer records the source commit or release,
  source artifact digest, assessment date, mapped rows, and staged rows. It
  maps only exact checks verified against the supported upstream revision.

AI Flight Deck does not currently copy or redistribute source code from the
Microsoft assessment repository. It consumes report output generated by that
tool. If upstream source code is copied or adapted later, the applicable
Microsoft copyright and MIT permission notice must be retained with the copied
or substantial portions.
